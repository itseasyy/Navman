***Navman*** is an open-source library that makes Roblox UI work everywhere **instantly**. It drops the headache of cross-platform setup, giving you a clean, simple API to get *controllers*, *keyboards*, and *mobile menus* running in minutes.

> [!IMPORTANT]
> This API is still in **early-development**, bugs may occur. If you run into any, please go ahead and **report it**.

## Why Navman?

If you've ever tried to add controller support to your game, you know how **frustrating** Roblox's default UI Navigation can be. ***Navman*** aims to make UI Navigation *easier*, and *universal* on all platforms. Giving developers **full control** on the elements the users get to interact with. Allowing for a more *seamless* playing experience.
### 🚀 Key Features

* **Cross-Platform**: Built from the ground up to unify controllers, keyboards, and touchscreens into one seamless navigation experience.
* **UI-Contexts**: Create digital blueprints for your menus, managing player inputs and defining how buttons connect and interact.
* **Event Binding**: Create custom UI events that can be triggered through scripts or bound directly to keys and buttons.
* **Full UI-Control**: Trigger any button through scripts, bind it to a key or button, or link it to another button for flexible interactions.

## Installation

To install **Navman**, use your preferred method

### Wally Installation

To install Navman with **wally**, add it to the dependencies
```toml
Navman = "itseasyy/navman@0.1.0-test.1"
```
Then run the following command in the terminal to install it
```bash
wally install
```

### Roblox Installation

Go to the [releases](https://github.com/itseasyy/Navman) tab, and install the **.rbxm** file, then drag and drop it into your game.
